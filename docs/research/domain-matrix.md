# ETL Research — Domain Matrix

## Research matrix

| Domain | Representative data | ETL / normalization operations | Typical use | Open-source building blocks | Repository status |
| --- | --- | --- | --- | --- | --- |
| Security / SOC | IPv4, IPv6, CIDR, ASN, MAC | Canonical IP/CIDR, ASN normalization, GeoIP/RDAP enrichment | SIEM correlation, attack-source analysis | [MaxMind GeoIP2](https://github.com/maxmind/GeoIP2-python), [ipwhois](https://github.com/secynic/ipwhois) | IP/CIDR + ASN scalar normalization implemented; GeoIP/RDAP stays enrichment |
| Security / Logs | Syslog, firewall, router, WAF, IDS | Grok/Dissect parsing, timestamp/severity/protocol normalization | Structured SIEM events | [Logstash Grok](https://www.elastic.co/guide/en/logstash/current/plugins-filters-grok.html) | Parser stage; common timestamp/text helpers implemented |
| Security / CTI | STIX, CVE, MITRE ATT&CK, IOC hashes | STIX IDs/types, CVE, ATT&CK technique IDs, digest normalization | Threat graph, CTI interchange | [python-stix2](https://github.com/oasis-open/cti-python-stix2), [STIX Validator](https://github.com/oasis-open/cti-stix-validator) | Scalar normalizers implemented; full STIX validation remains parser/validator stage |
| Security / Malware | Binary files, MD5/SHA1/SHA256, YARA matches | Hashing, digest classification, MIME/magic-byte inspection | Malware deduplication and IOC extraction | [YARA](https://github.com/VirusTotal/yara), [YARA-X](https://github.com/VirusTotal/yara-x) | Hash normalization implemented; file/YARA processing remains parser stage |
| Banking / Privacy | PAN, account IDs, PII | Masking, deterministic fingerprinting, tokenization boundaries | PCI/privacy-safe processing | [Microsoft Presidio](https://github.com/microsoft/presidio) | Masking + SHA-256 fingerprint implemented; secure token vault is external |
| Banking / Money | Amounts, currencies, rates | Exact decimal normalization, ISO-like currency-code shape | Reconciliation and financial aggregation | Python `decimal`, [Babel](https://github.com/python-babel/babel) | Decimal/currency/percentage/probability normalizers implemented |
| Banking / Payments | IBAN, BIC/SWIFT, ISO 20022 | IBAN checksum, BIC syntax, ISO 20022 message-type normalization | Cross-border payment integration | [schwifty](https://github.com/mdomke/schwifty), [Moov ISO20022](https://github.com/moov-io/iso20022) | IBAN/BIC/message-type scalar helpers implemented; XML/XSD parsing external |
| Citizen / Identity | CCCD, CMND, passport, IDs | Trim/separator removal, structural validation, classification | Cross-system identity linking | [python-stdnum](https://github.com/arthurdejong/python-stdnum) | VN CMND/CCCD structural helpers implemented; authoritative validation external |
| Citizen / Names | Vietnamese and multilingual names | Unicode NFC, whitespace normalization, accent-insensitive search key | Search, blocking, entity resolution | [ICU](https://github.com/unicode-org/icu) | Implemented |
| Citizen / Address | Free-text addresses, admin codes | Text normalization, component parsing, geocoding, admin-code mapping | Geography and cross-source matching | [libpostal](https://github.com/openvenues/libpostal), [Nominatim](https://nominatim.org/) | Safe text normalizer implemented; parsing/geocoding/reference joins external |
| Tax / Enterprise | Vietnamese tax ID, enterprise IDs, LEI | Structural formatting, entity-type classification, LEI checksum | Registry linkage, compliance | [python-stdnum](https://github.com/arthurdejong/python-stdnum), [OpenSanctions](https://github.com/opensanctions/opensanctions) | VN tax ID + OSINT LEI helpers implemented |
| eKYC | Base64 images, selfie/document payloads | Decode limits, MIME check, hashing, object-storage handoff | Reduce DB payload, secure document handling | Pillow/OpenCV, [Presidio Image](https://microsoft.github.io/presidio/image-redactor/) | File/image parser stage; scalar fingerprints/masking available |
| eKYC / Scores | Liveness, face-match scores | Finite-number validation, probability/range checks | Fraud decision pipelines | General validation frameworks | Probability/range UDFs implemented; model thresholds remain business configuration |
| OCR / Documents | OCR JSON, bbox, confidence | JSON canonicalization/flattening, text normalization, confidence validation | Map OCR output to relational/search schemas | [Tesseract](https://github.com/tesseract-ocr/tesseract), [Unstructured](https://github.com/Unstructured-IO/unstructured) | JSON/text/quality helpers implemented; OCR itself external |
| Healthcare / FHIR | FHIR JSON/XML IDs and references | FHIR `id` and relative reference normalization | EHR interoperability | [HAPI FHIR](https://github.com/hapifhir/hapi-fhir) | Scalar ID/reference helpers implemented; full profile validation external |
| Healthcare / HL7 v2 | MSH message type, segment payloads | Message-type normalization, segment parsing upstream | HIS/LIS/RIS integration | [HL7apy](https://github.com/crs4/hl7apy) | HL7 message-type scalar helper implemented; full message parser external |
| Healthcare / DICOM | Study/Series/SOP UID, modality, files | UID/modality normalization, PHI de-identification, metadata extraction | PACS and imaging analytics | [pydicom](https://github.com/pydicom/pydicom) | UID/modality helpers implemented; file parsing/de-identification external |
| Healthcare / Units | Lab measurements and unit codes | Unit parsing/conversion, terminology mapping | Cross-hospital comparison | [Pint](https://github.com/hgrecco/pint), [ucumvert](https://github.com/dalito/ucumvert) | Planned dependency-backed enrichment pack |
| Telecom | MSISDN, IMSI, IMEI | E.164 normalization, identifier validation, masking | Subscriber analytics and fraud | [libphonenumber](https://github.com/google/libphonenumber), [pycrate](https://github.com/pycrate-org/pycrate) | Generic/VN E.164 shape helper implemented; IMSI/IMEI planned |
| Telecom / CDR | ASN.1/BER CDR | ASN.1 decoding, vendor/release schema selection, event flattening | Billing/QoS/fraud analytics | [pycrate](https://github.com/pycrate-org/pycrate) | Parser stage |
| Education | Student, teacher, school IDs, school year | Code normalization, academic-year normalization, entity blocking | Multi-source education integration | Domain reference data + generic libraries | VN school/teacher/student/year helpers implemented |
| Learning analytics | xAPI statements | Actor/verb/object/timestamp normalization and statement dedupe | LRS and learning analytics | [xapi-schema](https://github.com/yetanalytics/xapi-schema) | Planned standards pack |
| E-commerce | Product, SKU, variants, attributes JSON | JSON flattening, decimal/stock/rating validation, canonical IDs | Catalog integration and price intelligence | `pandas.json_normalize`, JSON Schema | Common JSON/decimal/quality helpers implemented; marketplace taxonomy mapping external |
| Entity resolution | Product/shop/person/company aliases | Search keys, blocking keys, fuzzy/probabilistic matching | Deduplication and cross-source entity linking | [RapidFuzz](https://github.com/rapidfuzz/RapidFuzz), [Splink](https://github.com/moj-analytical-services/splink), [dedupe](https://github.com/dedupeio/dedupe) | Blocking/search helpers implemented; probabilistic matching external |
| Supply chain | GTIN, SSCC, EPCIS events | GS1 check digit, EPCIS event-type normalization | Traceability and Digital Product Passport | [OpenEPCIS](https://github.com/openepcis) | GTIN/SSCC/EPCIS scalar helpers implemented |
| Public transport | GTFS IDs, lat/lon | ID normalization, coordinate validation, feed validation | Journey planning and operations | [MobilityData GTFS Validator](https://github.com/MobilityData/gtfs-validator) | GTFS ID + lat/lon helpers implemented; whole-feed validation external |
| GIS | CRS/EPSG, point/polygon/raster | EPSG normalization, CRS conversion, geometry repair, spatial indexing | Large-scale spatial analytics | [GDAL](https://github.com/OSGeo/gdal), [PROJ](https://github.com/OSGeo/PROJ), [H3](https://github.com/uber/h3) | EPSG/coordinate scalar helpers implemented; geometry/raster processing external |
| Manufacturing | OPC UA NodeId, status | NodeId canonicalization, engineering-unit/quality mapping | Machine/SCADA ingestion | [open62541](https://github.com/open62541/open62541) | OPC UA NodeId + telemetry quality implemented; protocol client external |
| IoT | MQTT topic/payload, telemetry | JSON/CBOR/Protobuf decode, timestamp/unit/quality normalization | Real-time device telemetry | [Eclipse Paho](https://github.com/eclipse-paho/paho.mqtt.python), [Telegraf](https://github.com/influxdata/telegraf) | Scalar quality/common transforms implemented; MQTT/protobuf decoding external |
| Energy / Metering | DLMS/COSEM, OBIS | OBIS normalization, interval/unit normalization | Smart-meter billing/load profile | [Gurux DLMS](https://github.com/Gurux/Gurux.DLMS.Python) | OBIS helper implemented; DLMS protocol client external |
| Climate / Ocean | NetCDF, GRIB, CF metadata | CF standard-name normalization, GRIB short-name normalization, chunk/decode upstream | Weather and climate analytics | [xarray](https://github.com/pydata/xarray), [cfgrib](https://github.com/ecmwf/cfgrib) | Metadata scalar helpers implemented; NetCDF/GRIB file parsing external |
| Documents | PDF, Office, HTML, WARC | MIME/text extraction, content hashing, OCR fallback, provenance | Search/RAG/document lake | [Apache Tika](https://github.com/apache/tika), [Unstructured](https://github.com/Unstructured-IO/unstructured), [warcio](https://github.com/webrecorder/warcio) | Common hash/JSON/text/provenance helpers implemented; document parsing external |

| Genomics | chromosome, DNA, VCF genotype, SAM/BAM/CRAM | chromosome/sequence/genotype normalization, variant normalization upstream | Genomic analytics | [HTSlib](https://github.com/samtools/htslib), [BCFtools](https://github.com/samtools/bcftools) | Chromosome/DNA/genotype helpers implemented; BAM/VCF parsing external |
| Astronomy | FITS keyword, celestial frame, FITS/WCS files | Keyword/frame normalization, WCS/file validation upstream | Astronomy metadata integration | [Astropy](https://github.com/astropy/astropy) | FITS keyword/frame helpers implemented; FITS/WCS parsing external |
| Insurance | ACORD version, policy number, coverage code, XML | Version/code normalization, XSD validation upstream | Insurer/broker/reinsurer integration | ACORD XML implementations/samples | Scalar helpers implemented; ACORD XML/XSD parser external |
