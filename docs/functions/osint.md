# Hàm OSINT

Đăng ký bằng `register_osint_udfs(t_env)`.

OSINT UDF chỉ chuẩn hóa observation/evidence/identifier. Kết quả tìm thấy trên nguồn mở **không tự động trở thành sự thật đã xác minh**; entity resolution và verification phải giữ provenance/confidence riêng.

| Tên hiển thị | SQL function | Chuẩn / phạm vi | Mô tả | Giá trị trước → sau | Ví dụ SQL |
| --- | --- | --- | --- | --- | --- |
| Tạo ID observation ổn định | `osint_build_observation_id` | SHA-256 provenance key | Hash `source_url + entity_key + observed_at` để cùng observation có ID ổn định, hỗ trợ dedup và history. | `https://example.gov.vn/thong-bao/123`, `org:0101234567`, `2026-08-10T07:30:00Z` → `eaaa5f24363feefb42fb46ad1c5156736b3b20adef1ab7bfffea8712e9165d39` | `SELECT osint_build_observation_id(source_url, entity_key, observed_at);` |
| Chuẩn hóa URL nguồn | `osint_canonicalize_url` | HTTP(S) canonicalization | Lowercase scheme/host, bỏ userinfo, fragment và tracking params, sort query params. | `HTTPS://user:pass@Example.COM:443/profile/123?utm_source=mail&id=123#bio` → `https://example.com/profile/123?id=123` | `SELECT osint_canonicalize_url(source_url);` |
| Phân loại định danh tài khoản | `osint_classify_account_identifier` | Conservative syntax heuristic | Phân loại input thành `email`, `phone` hoặc `username`; không chứng minh chủ sở hữu. | `canbo@example.gov.vn` → `email` | `SELECT osint_classify_account_identifier(account_key);` |
| Phân loại hash Git object | `osint_classify_git_object_hash` | Git object ID | Phân loại full object ID 40 hex là `sha1`, 64 hex là `sha256`. | `aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa` → `sha1` | `SELECT osint_classify_git_object_hash(commit_hash);` |
| Phân loại hash file | `osint_classify_hash_type` | MD5 / SHA-1 / SHA-256 / SHA-512 shape | Xác định loại digest theo độ dài sau khi validate chuỗi hex. | `aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa` → `sha256` | `SELECT osint_classify_hash_type(file_hash);` |
| Hash nội dung bằng SHA-256 | `osint_content_sha256` | Evidence integrity / dedup | Tạo SHA-256 cho raw text evidence để so sánh snapshot và phát hiện nội dung thay đổi. | `<html>thong bao dau thau</html>` → `1a6fda9e632ea2fb8d91545f8fd36546e9aebf4781c243a6ab54620b9424f194` | `SELECT osint_content_sha256(raw_content);` |
| Lấy hostname từ URL | `osint_extract_url_host` | HTTP(S) URL | Canonicalize URL rồi lấy hostname đã normalize. | `https://Portal.EXAMPLE.GOV.VN/profile?id=1` → `portal.example.gov.vn` | `SELECT osint_extract_url_host(source_url);` |
| Chuẩn hóa ASN | `osint_normalize_asn` | 32-bit ASN | Chuẩn hóa Autonomous System Number về `AS<number>`. | `as13335` → `AS13335` | `SELECT osint_normalize_asn(asn);` |
| Chuẩn hóa confidence | `osint_normalize_confidence` | Numeric 0..1 | Parse finite confidence score trong miền `0..1`. | `0.82` → `0.82` | `SELECT osint_normalize_confidence(confidence);` |
| Chuẩn hóa CVE ID | `osint_normalize_cve` | CVE identifier syntax | Chuẩn hóa CVE về `CVE-YYYY-NNNN...`. Không lookup CVE record. | `cve 2024 12345` → `CVE-2024-12345` | `SELECT osint_normalize_cve(cve_id);` |
| Chuẩn hóa loại DNS record | `osint_normalize_dns_record_type` | DNS RR controlled set | Uppercase và chỉ nhận các record type phổ biến được hỗ trợ. | `aaaa` → `AAAA` | `SELECT osint_normalize_dns_record_type(record_type);` |
| Chuẩn hóa domain | `osint_normalize_domain` | DNS / IDNA | Bỏ trailing dot, chuyển Unicode domain sang IDNA ASCII và lowercase. | `BÜCHER.DE.` → `xn--bcher-kva.de` | `SELECT osint_normalize_domain(domain);` |
| Chuẩn hóa loại thực thể | `osint_normalize_entity_type` | OSINT graph vocabulary | Map alias phổ biến sang vocabulary như `person`, `organization`, `domain`, `ip_address`. | `company` → `organization` | `SELECT osint_normalize_entity_type(entity_type);` |
| Chuẩn hóa trạng thái lộ lọt | `osint_normalize_exposure_status` | Credential exposure workflow | Map trạng thái remediation về `open`, `remediated`, `suppressed`, `unknown`. | `resolved` → `remediated` | `SELECT osint_normalize_exposure_status(exposure_status);` |
| Chuẩn hóa Git object ID | `osint_normalize_git_object_id` | Git full SHA-1 / SHA-256 ID | Lowercase full 40/64-char object ID; reject abbreviated commit ID để giảm collision khi tích hợp nhiều repo. | `AAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAA` → `aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa` | `SELECT osint_normalize_git_object_id(commit_hash);` |
| Chuẩn hóa hash hex | `osint_normalize_hex_hash` | MD5/SHA family shape | Lowercase digest và chỉ nhận độ dài tương ứng các hash type phổ biến. | `AAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAA` → `aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa` | `SELECT osint_normalize_hex_hash(file_hash);` |
| Chuẩn hóa LEI | `osint_normalize_lei` | ISO 17442 + mod-97 | Uppercase, validate 20 ký tự và mod-97 của Legal Entity Identifier. | `5493001KJTIIGC8Y1R12` → `5493001KJTIIGC8Y1R12` | `SELECT osint_normalize_lei(lei);` |
| Chuẩn hóa MIME type | `osint_normalize_mime_type` | MIME media type syntax | Lowercase media type và bỏ parameter như charset. | `Text/HTML; charset=UTF-8` → `text/html` | `SELECT osint_normalize_mime_type(content_type);` |
| Khóa tìm kiếm tên OSINT | `osint_normalize_name_search_key` | Candidate-generation search key | NFKD, bỏ dấu kết hợp, lowercase và normalize punctuation để tìm candidate. Không dùng làm canonical identity. | `Nguyễn Văn An` → `nguyen van an` | `SELECT osint_normalize_name_search_key(display_name);` |
| Chuẩn hóa thời điểm quan sát | `osint_normalize_observed_at_utc` | ISO 8601 → UTC | Chuyển timestamp observation có timezone về UTC `Z`; reject naive timestamp. | `2026-08-10T14:30:00+07:00` → `2026-08-10T07:30:00Z` | `SELECT osint_normalize_observed_at_utc(observed_at);` |
| Chuẩn hóa tỷ lệ sở hữu | `osint_normalize_ownership_percentage` | Numeric 0..100 | Bỏ `%`, parse finite float trong `0..100`. | `25.5%` → `25.5` | `SELECT osint_normalize_ownership_percentage(ownership_pct);` |
| Chuẩn hóa tên platform | `osint_normalize_platform` | Platform/domain label | Lowercase, bỏ prefix `www.` và trailing dot để group observation theo platform ổn định. | `WWW.Tumblr.COM.` → `tumblr.com` | `SELECT osint_normalize_platform(platform);` |
| Chuẩn hóa URL profile | `osint_normalize_profile_url` | HTTP(S) profile URL | Canonicalize profile URL rồi bỏ query/fragment để tránh tạo nhiều entity key cho cùng profile. | `https://Example.com/user/an?ref=x#bio` → `https://example.com/user/an` | `SELECT osint_normalize_profile_url(profile_url);` |
| Chuẩn hóa repository URL | `osint_normalize_repository_url` | HTTP(S) Git repository URL | Canonicalize URL và bỏ suffix `.git`, query/fragment. | `https://github.com/org/repo.git?utm_source=x` → `https://github.com/org/repo` | `SELECT osint_normalize_repository_url(repo_url);` |
| Chuẩn hóa username | `osint_normalize_username` | Public account handle | Trim, Unicode NFC, bỏ các `@` ở đầu nhưng giữ case vì semantics phụ thuộc platform. | ` @@User.Name ` → `User.Name` | `SELECT osint_normalize_username(username);` |
| Chuẩn hóa trạng thái xác minh | `osint_normalize_verification_status` | OSINT verification vocabulary | Map label về `unverified`, `machine_correlated`, `analyst_reviewed`, `confirmed`, `rejected`. | `reviewed` → `analyst_reviewed` | `SELECT osint_normalize_verification_status(status);` |
| Che secret trong URL | `osint_redact_url_secrets` | Privacy / logging safety | Bỏ URL userinfo và thay giá trị của token/password/api-key... bằng `[REDACTED]` trước khi log/lưu. | `https://api.example.gov.vn/a?token=abc&id=12` → `https://api.example.gov.vn/a?token=%5BREDACTED%5D&id=12` | `SELECT osint_redact_url_secrets(request_url);` |

## Lưu ý thiết kế

Các hàm OSINT không thực hiện crawler, RDAP lookup, DNS query, sanctions lookup hoặc social-platform API call. Những tác vụ có I/O/rate-limit/cache nên chạy ở async enrichment/operator riêng; scalar UDF chỉ canonicalize dữ liệu đã thu thập.
